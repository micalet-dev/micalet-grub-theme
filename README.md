# Micalet GRUB Theme

Minimal GRUB 2 theme for Micalet GNU/Linux.

## Design

- Plain teal gradient background (`theme/background.png`).
- Simple centered MICALET heading.
- Four-entry boot menu supplied by Micalet's `grub.cfg`.
- High-contrast selected entry using the nine-slice `select_*.png` images.
- No decorative illustrations or icons.

## Installed systems

The Debian package installs the theme under `/usr/share/grub/themes/micalet/` and provides a GRUB defaults fragment at `/etc/default/grub.d/50-micalet-theme.cfg`.
